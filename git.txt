================================================================================
GIT COMMANDS CHEATSHEET & STEP-BY-STEP WORKFLOW
Project: CREATIVE-ARENA
Remote: https://github.com/ABHI-MANDA/creative-arena.git
================================================================================

1. CHECK CURRENT REPOSITORY STATUS
--------------------------------------------------------------------------------
Command:
git status

Description:
Shows the state of the working directory and staging area. Displays which files
are tracked, untracked, modified, or staged for commit.


2. LIST ALL TRACKED FILES
--------------------------------------------------------------------------------
Command:
git ls-files

Description:
Lists all files currently being tracked by Git. Useful for identifying whether
generated files or build caches (e.g. tsconfig.tsbuildinfo) were committed by mistake.


3. UNTRACK PREVIOUSLY COMMITTED BUILD ARTIFACTS
--------------------------------------------------------------------------------
Command:
git rm --cached tsconfig.tsbuildinfo

Description:
Removes the specified file from Git's index/tracking while keeping the physical
file intact on your local disk. Used here to stop tracking the TypeScript build cache.


4. VERIFY .gitignore MATCHING RULES
--------------------------------------------------------------------------------
Command:
git check-ignore -v .env .next node_modules .local-db tsconfig.tsbuildinfo

Description:
Verifies that .gitignore rules correctly match and exclude sensitive files (.env),
local databases (.local-db), build outputs (.next), and dependency directories (node_modules).


5. CONFIGURE GIT USER IDENTITY (IF NOT ALREADY SET)
--------------------------------------------------------------------------------
Command:
git config user.name "Abhishek Kumar"
git config user.email "161799741+Abhishek-kumar-abhi@users.noreply.github.com"

Description:
Sets your commit author name and email locally for this repository so commits
are properly attributed to your GitHub account.


6. STAGE REPOSITORY CHANGES FOR COMMIT
--------------------------------------------------------------------------------
Command:
git add .

(or individually):
git add .gitignore .env.example package-lock.json postcss.config.mjs next-env.d.ts src/

Description:
Adds all modified and newly created files (.gitignore, .env.example, source code,
and project configuration) to the Git staging area ready for commit. Because .gitignore
is active, .env, .next, node_modules, and .local-db are safely ignored and not staged.


7. COMMIT THE STAGED CHANGES
--------------------------------------------------------------------------------
Command:
git commit -m "Configure .gitignore, add .env.example, and untrack build artifacts"

Description:
Records staged snapshots into the Git commit history with a clear and descriptive
message explaining the changes.


8. UPDATE REMOTE REPOSITORY URL
--------------------------------------------------------------------------------
Command:
git remote set-url origin https://github.com/ABHI-MANDA/creative-arena.git

Description:
Updates the URL of the 'origin' remote repository to point to your target GitHub repository.


9. VERIFY CONFIGURED REMOTES
--------------------------------------------------------------------------------
Command:
git remote -v

Description:
Displays the fetch and push URLs for all configured remote repositories to confirm
they point to the correct GitHub URL.


10. ADD WEBSITE ICON & COMMIT
--------------------------------------------------------------------------------
Command:
git add src/app/layout.tsx public/favicon.ico src/app/icon.png
git commit -m "feat: add brand logo as website favicon and app icon"

Description:
Adds the brand logo as the official browser tab icon (favicon) through Next.js
app router metadata, /icon.png route, and public/favicon.ico fallback.


11. FIX DYNAMIC GREETING & TIMESTAMPS FOR PRODUCTION HOSTING
--------------------------------------------------------------------------------
Command:
git add src/app/admin/page.tsx src/app/assets/library.tsx src/app/page.tsx src/components/cards.tsx src/components/live-time.tsx src/lib/utils.ts
git commit -m "fix: make greeting and timestamps dynamic in production using client timezone and live ticking"

Description:
Replaces server-static UTC time calculations with client-adaptive dynamic components
(HeroGreeting, LiveTimeAgo, LiveExactTime, LiveActivityTimestamp). Resolves the issue
where production cloud servers running in UTC timezone always served 'Good morning' and
stale UTC timestamps.


12. PUSH CHANGES TO GITHUB
--------------------------------------------------------------------------------
Command:
git push -u origin main

(or):
git push origin main

Description:
Uploads your local commits from branch 'main' to GitHub.
Note: If prompted in terminal or browser, authenticate with your GitHub credentials
or a GitHub Personal Access Token (PAT).
